# IELTIX — Senior AI Exam Preparation Platform (IELTS & Milliy BBM)

IELTIX — Sun'iy intellekt asosida ishlovchi ilg'or imtihonlarga tayyorgarlik platformasi (IELTS va Milliy BBM sertifikatlari).

## 📁 Repository Tarkibi

- **`IELTIX_platform/`**: Senior darajadagi to'liq Full-Stack loyiha:
  - **`frontend/`**: React 19 + TypeScript + Vite + Tailwind CSS (Stitch dizayni asosida 9 ta to'liq interaktiv modul, Web Speech API, audio pleyer, split-screen imtihon simulyatorlari).
  - **`backend/`**: Node.js + Express + TypeScript REST API (Speaking, Writing, Reading, Listening, Vocab Vault, QR sertifikat).
- **`IELTIX/`**: Google Stitch orqali yaratilgan original UI/UX dizaynlar va andozalar (Obsidian Flux Dark va EduTest AI Light rejimlar).

## 🚀 Ishga Tushirish

### Backend (Port 5000)
```bash
cd IELTIX_platform/backend
npm install
npm run dev
```

### Frontend (Port 5173)
```bash
cd IELTIX_platform/frontend
npm install
npm run dev
```
Brauzerda: `http://localhost:5173/`
